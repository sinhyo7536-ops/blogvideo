# 내장 배경음악 라이선스

이 폴더의 곡은 외부 음원이 아니라 `packaging/make_music.py`가 코드로 직접 합성한 곡입니다.
저작권 문제가 없도록 CC0 1.0(퍼블릭 도메인 기증)으로 공개합니다.
유튜브 영상에 자유롭게 써도 되고, 출처를 표시할 필요가 없습니다.

| 파일 | 만든 방법 | 라이선스 |
|---|---|---|
| 잔잔한_피아노풍.mp3 | make_music.py (72 BPM, 아르페지오) | CC0 1.0 |
| 밝은_산책.mp3 | make_music.py (100 BPM, 아르페지오) | CC0 1.0 |
| 포근한_공간.mp3 | make_music.py (60 BPM, 패드) | CC0 1.0 |

다른 음악을 쓰고 싶으면 프로그램의 "설정 → 배경음악 추가"에서 MP3를 올리세요.
유튜브 스튜디오의 "오디오 보관함" 곡처럼 사용 허락이 확인된 음악만 쓰세요.
