# 블로그 → 유튜브 영상 변환기 설계

- 작성일: 2026-11-12
- 상태: 검토 대기

## 1. 목적

네이버 블로그 글 링크를 넣으면, 블로그 사진·큰 자막·AI 성우·배경음악으로 구성된
영상(MP4)을 만들어 주는 프로그램. 참고: 비디오스튜의 "부동산 매물 소개 블로그를
영상으로 변환하기" 스타일.

**실사용자는 개발자가 아닌 지인**(컴퓨터 초보)이다. 설치 파일 더블클릭만으로
설치되고, 바탕화면 아이콘으로 실행되어야 한다.

## 2. 확정된 요구사항

| 항목 | 결정 |
|---|---|
| 입력 | 네이버 블로그 글 링크 |
| 영상 스타일 | 블로그 사진 + 큰 자막 + AI 성우 + 배경음악 |
| 화면 비율 | 가로(16:9, 1920×1080) / 세로(9:16, 1080×1920) 중 매번 선택 |
| 대본 | Claude API가 글을 장면 단위로 요약 |
| 음성 | Edge TTS (무료, 한국어 남/여 음성) |
| 흐름 | 대본 수정 → 영상 생성 → 미리보기 → 저장 |
| 유튜브 업로드 | **반자동**: MP4 저장 + 제목/설명/태그 복사 버튼. 업로드는 지인이 유튜브 앱에서 직접 |
| 실행 환경 | 지인의 윈도우 PC에서 실행하는 웹 앱 |
| 모바일 | 같은 와이파이의 휴대폰 브라우저에서 PC와 동일하게 사용 |
| API 키 | 배포자(사용자)가 발급해 설정 화면에 입력, 지인 PC에 저장 |
| 배경음악 | 라이선스가 확인된 무료(CC0 등) 곡 3~5개 내장 + 사용자 MP3 추가 가능 |

### 범위 밖 (하지 않음)

- 유튜브 API 자동 업로드 (미심사 프로젝트는 영상이 비공개로 잠기고, 로그인이 7일마다 만료됨)
- 네이버 외 블로그 플랫폼 (추출기 구조는 확장 가능하게 둠)
- 외부(다른 네트워크)에서의 접속, 다중 사용자, 로그인
- 맥/리눅스용 설치 파일

## 3. 사용 흐름 (지인 기준)

1. `블로그영상변환기_설치.exe` 실행 → 설치 → 바탕화면 아이콘 생성.
2. 아이콘 실행 → 백그라운드 서버 시작 → PC 기본 브라우저가 자동으로 열림.
   화면 상단에 휴대폰 접속용 주소와 **QR코드** 표시.
3. 링크 붙여넣기, 비율(가로/세로)·성우(남/여)·배경음악 선택 → "대본 만들기".
4. 장면 편집 화면: 장면마다 자막 문장 수정, 사진 교체(블로그 사진 중 선택), 장면 삭제·순서 변경.
   유튜브 제목/설명/태그도 수정 가능.
5. "영상 만들기" → 진행률 표시 → 완료 시 미리보기 재생.
6. "영상 저장"(다운로드) + 제목/설명/태그 각각 "복사" 버튼.
   휴대폰에서는 다운로드 후 유튜브 앱으로 업로드.

최초 1회 배포자가 "설정" 화면에서 Claude API 키를 입력한다. 키가 없으면
대본 만들기 버튼 대신 "설정에서 API 키를 입력해 주세요" 안내를 띄운다.

## 4. 구조

Python 단일 프로세스 웹 앱. 기능별로 독립된 모듈로 나눈다.

```
app/
  main.py          FastAPI 앱, 라우트, 작업 상태 관리
  config.py        설정 저장/로드 (%APPDATA%\BlogVideo\config.json)
  scraper/
    naver.py       네이버 블로그 → BlogPost(제목, 문단 목록, 이미지 URL 목록)
  script.py        BlogPost → VideoScript(장면 목록, 제목, 설명, 태그) via Claude
  tts.py           장면 문장 → 음성 파일(mp3) + 길이(초)
  render.py        VideoScript + 이미지 + 음성 + BGM → MP4 (FFmpeg)
  jobs.py          작업 폴더/진행 상태 관리
  web/             HTML/CSS/JS (모바일 우선 반응형, 빌드 도구 없음)
assets/
  fonts/           한글 폰트 (OFL 라이선스, 예: Noto Sans KR / Pretendard)
  music/           내장 배경음악 + LICENSES.md (곡별 출처·라이선스)
packaging/
  launcher.py      서버 시작 + 브라우저 열기 + 트레이/콘솔 숨김
  installer.iss    Inno Setup 스크립트 (방화벽 규칙, 바로가기)
.github/workflows/
  build-windows.yml  윈도우 러너에서 PyInstaller + Inno Setup → 설치 파일 산출
tests/
```

### 4.1 데이터 모델

- `BlogPost`: `title`, `paragraphs: list[str]`, `images: list[ImageRef]` (URL, 원문 내 순서)
- `Scene`: `text`(자막·내레이션 문장), `image_index`, `duration`(TTS 후 채움)
- `VideoScript`: `scenes: list[Scene]`, `yt_title`, `yt_description`, `yt_tags: list[str]`
- `RenderOptions`: `aspect`("16:9"|"9:16"), `voice`("female"|"male"), `bgm`(파일명|없음), `bgm_volume`

### 4.2 모듈별 동작

**scraper/naver.py**
- 입력 URL 형태: `blog.naver.com/{id}/{logNo}`, `m.blog.naver.com/...`, `PostView.naver?blogId=&logNo=`.
- `blogId`, `logNo`를 뽑아 모바일 페이지(`m.blog.naver.com/{id}/{logNo}`)에서 SmartEditor 본문
  (`.se-main-container`)의 텍스트 문단과 이미지를 원문 순서대로 추출.
- 이미지는 고해상도 원본 URL로 바꿔 작업 폴더에 내려받는다(네이버 이미지는 Referer 필요).
- 실패(비공개 글, 삭제된 글, 형식 불일치)는 `ScrapeError`와 사용자용 메시지로 반환.

**script.py**
- Claude API에 글 제목·문단·이미지 개수를 주고, 정해진 JSON 형식으로 받는다:
  장면 6~12개, 장면당 자막 1~2문장(장면당 약 40자 이내), 장면별 이미지 번호,
  유튜브 제목(60자 이내)·설명·태그.
- 응답 형식 검증 실패 시 1회 재시도, 다시 실패하면 오류.
- 이미지 번호가 범위를 벗어나면 순서대로 보정.

**tts.py**
- `edge-tts`로 장면별 mp3 생성. 음성: 여 `ko-KR-SunHiNeural`, 남 `ko-KR-InJoonNeural`.
- 실제 길이를 측정(ffprobe)해 `Scene.duration` = 음성 길이 + 여유 0.4초.

**render.py**
- 장면별 클립: 이미지를 비율에 맞게 꽉 채워 자르고(cover), 천천히 확대(Ken Burns, zoompan).
  하단에 반투명 띠 + 큰 한글 자막(내장 폰트, 외곽선). 세로 영상은 자막 크기·위치 조정.
- 클립 연결 시 짧은 페이드 전환.
- 내레이션 트랙 + 배경음악(반복·끝부분 페이드아웃, 기본 볼륨 15%) 믹스.
- 출력: H.264 + AAC, 30fps, MP4(`+faststart`, 휴대폰 미리보기용).
- FFmpeg 진행률(`-progress`)을 읽어 작업 진행률에 반영.

**jobs.py / main.py**
- 작업 단위 폴더: `%LOCALAPPDATA%\BlogVideo\jobs\{job_id}\` (이미지, 음성, 결과 MP4, script.json).
- 단계: 추출 → 대본 → (사용자 편집) → 음성 → 렌더링. 각 단계는 백그라운드 스레드로 실행하고
  상태(단계, 진행률, 오류 메시지)를 API로 조회(폴링).
- 실패한 단계만 다시 실행 가능.
- 오래된 작업 폴더(7일 경과)는 시작 시 정리.

### 4.3 웹 화면

- 빌드 도구 없는 순수 HTML/CSS/JS. 모바일 우선 레이아웃, 버튼은 터치하기 쉬운 크기(최소 44px).
- 화면: ① 링크 입력 ② 장면 편집 ③ 진행/미리보기/저장 ④ 설정(API 키, 배경음악 추가).
- 문구는 모두 쉬운 한국어.

### 4.4 휴대폰 접속

- 서버는 `0.0.0.0:8765`에서 대기. 시작 시 PC의 사설 IP를 찾아 `http://{IP}:8765` 주소와 QR코드를 표시.
- 설치 프로그램이 해당 포트에 대해 **개인(사설) 네트워크 전용** 윈도우 방화벽 인바운드 규칙을 추가.
- 같은 네트워크 사람이면 누구나 접속할 수 있으므로, 설정 화면(API 키)은 PC 본인(localhost)에서만 열리게 한다.

## 5. 배포

- **PyInstaller**로 Python 런타임과 의존성을 하나의 폴더로 묶는다.
- `ffmpeg.exe`/`ffprobe.exe`(LGPL/GPL 빌드, 라이선스 고지 포함), 한글 폰트, 내장 음악을 같이 넣는다.
- **Inno Setup**으로 설치 파일 생성: 설치 경로, 바탕화면/시작 메뉴 바로가기, 방화벽 규칙, 제거 프로그램.
- **GitHub Actions(windows-latest)** 에서 태그 푸시 또는 수동 실행 시 빌드하여 설치 파일을 아티팩트/릴리스로 올린다.
  배포자는 이 파일만 받아 지인에게 전달한다.
- 코드 서명은 하지 않는다. 처음 실행 시 윈도우 SmartScreen 경고("추가 정보 → 실행")가 뜰 수 있으며,
  이를 지인용 안내서에 그림과 함께 설명한다.

## 6. 오류 처리

| 상황 | 사용자에게 보이는 메시지 |
|---|---|
| 네이버 링크 아님 | "네이버 블로그 글 주소를 넣어 주세요." |
| 비공개/삭제 글 | "글을 읽을 수 없어요. 전체공개 글인지 확인해 주세요." |
| 인터넷 끊김 | "인터넷 연결을 확인해 주세요." + 다시 시도 |
| API 키 없음/잘못됨 | "설정에서 API 키를 확인해 주세요." |
| AI 응답 형식 오류 | 자동 1회 재시도 후 "대본을 만들지 못했어요. 다시 시도해 주세요." |
| 음성 생성 실패 | 해당 장면만 재시도 |
| 렌더링 실패 | "영상을 만들지 못했어요." + 상세 로그는 `logs/`에 저장 |

## 7. 테스트

- 추출: 저장해 둔 네이버 HTML 샘플로 문단·이미지 순서 추출 검증 (네트워크 없이).
- 대본: Claude 응답을 가짜로 대체해 JSON 검증·보정 로직 검증.
- TTS: edge-tts를 가짜로 대체해 길이 계산 검증 + (선택) 실제 호출 1회.
- 렌더링: 작은 테스트 이미지 2~3장과 무음 음성으로 실제 FFmpeg 렌더 → 길이·해상도 검증 (16:9, 9:16 모두).
- 웹: 주요 API 라우트 테스트(FastAPI TestClient).
- 수동 검증: 실제 네이버 글 1편으로 전체 흐름 → 데스크톱/모바일 화면 크기 스크린샷 확인.
- 설치 파일: GitHub Actions에서 빌드 성공 + 설치된 실행 파일이 서버를 띄우는지 스모크 테스트.

## 8. 위험 요소

- **네이버 구조 변경**: 추출기가 깨질 수 있음 → 추출기를 별도 모듈로 두고 샘플 기반 테스트로 빠르게 고침.
- **Edge TTS는 비공식 엔드포인트**: 막히면 음성 생성이 안 됨 → TTS 모듈을 교체 가능한 인터페이스로 둔다.
- **API 키 노출**: 키가 지인 PC의 설정 파일에 평문 저장됨 → 배포자가 Anthropic 콘솔에서 사용 한도를 걸어 두도록 안내.
- **내장 음악 라이선스**: 출처·라이선스를 확인할 수 있는 곡만 넣고 `LICENSES.md`에 기록.
