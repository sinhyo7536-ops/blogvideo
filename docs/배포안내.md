# 배포 안내 (지인에게 전달하는 분용)

이 문서는 프로그램을 **지인에게 설치해 주는 사람**을 위한 안내입니다. 지인용 설명서는 [사용설명서.md](사용설명서.md)에 있습니다.

## 1. Claude API 키 만들기

1. <https://console.anthropic.com> 에 가입하고 로그인합니다.
2. **Billing(결제)** 에서 카드를 등록하고 크레딧을 충전합니다. (예: 5달러면 영상 약 50개 분량)
3. **API Keys → Create Key** 로 키를 만듭니다. `sk-ant-…` 로 시작하는 키를 복사해 둡니다.
   키는 만들 때 한 번만 보여 주니 안전한 곳에 적어 두세요.

### Gemini 무료 API 키 만들기
Claude 대신(또는 함께) 쓸 수 있는 무료 방법입니다. 두 키를 모두 넣어 두고 영상마다 골라 쓸 수 있습니다.
1. <https://aistudio.google.com/apikey> 에 구글 계정으로 로그인합니다.
2. **API 키 만들기(Create API key)** 를 눌러 `AIza…` 로 시작하는 키를 복사합니다.
3. 프로그램 **설정 → Gemini API 키(무료)** 에 넣고 **Gemini 키 저장**.
4. 처음 화면의 "대본 만드는 방법"에서 **Gemini(무료)** 를 고릅니다.
- 무료 사용분은 **하루 사용 횟수 제한**이 있고, 입력한 내용(공개 블로그 글)이 구글 서비스 개선에 쓰일 수 있습니다.
- "지인용 설치 파일 만들기"는 저장된 Claude·Gemini 키를 **둘 다** 넣어 줍니다.
- 키를 새로 넣거나 바꿨다면 지인용 설치 파일을 **다시 만들어** 보내면 됩니다.

### 꼭 해 두세요: 사용 한도 걸기
키는 지인 PC에 **윈도우 계정 암호화(DPAPI)** 로 저장됩니다. 설정 파일을 다른 PC나 다른 윈도우 계정으로 복사해 가도 키를 풀 수 없습니다.
다만 지인 PC의 그 윈도우 계정으로 로그인한 사람은 프로그램을 쓸 수 있으니, 혹시 모를 과다 사용을 막으려면:
- 콘솔의 **Limits(한도)** 에서 **월 사용 한도**를 작게(예: 월 5~10달러) 설정하세요.
- 이 프로그램 전용 키를 따로 만들어 쓰면, 문제가 생겼을 때 그 키만 끄면 됩니다.

> 비용 참고: 영상 하나의 대본을 만들 때 Claude(Opus 5.5)를 1번 호출합니다. 블로그 글 길이에 따라 대략 100~200원입니다.
> Claude Max·Pro 구독과는 별개로, 콘솔에 충전한 크레딧에서 빠져나갑니다.
> 성우 목소리(Edge TTS)와 영상 만들기는 무료입니다.
>
> **키 없이도 쓸 수 있습니다.** 처음 화면의 "대본 만드는 방법"에서 **AI 없이(무료)** 를 고르면 API 비용이 전혀 들지 않습니다.
> 키가 없으면 기본값이 "AI 없이(무료)"로 잡힙니다. 크레딧이 떨어져 유료 방식이 실패해도 오류 화면에서 무료 방법으로 이어서 할 수 있습니다.

## 2. 설치 파일 받기

설치 파일은 GitHub Actions가 자동으로 만듭니다.

1. 저장소의 **Actions** 탭 → **Build Windows installer** 를 엽니다.
2. 가장 최근의 초록색(성공) 실행을 누릅니다.
3. 아래 **Artifacts** 의 **BlogVideo-Setup** 을 눌러 받습니다(zip). 압축을 풀면 `BlogVideo-Setup.exe` 가 나옵니다.

정식 버전으로 남기고 싶으면 `v0.1.0` 같은 태그를 만들어 푸시하세요. **Releases** 에 설치 파일이 자동으로 첨부됩니다.

```bash
git tag v0.1.0
```

```bash
git push origin v0.1.0
```

## 3. 내 PC에서 먼저 테스트하기

1. 받은 `BlogVideo-Setup.exe` 를 **내 PC**에서 실행해 설치합니다.
   "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행** 을 누릅니다(코드 서명 인증서가 없어서 뜨는 경고입니다).
2. 프로그램이 열리면 오른쪽 위 **설정** → **Claude API 키** 칸에 키를 넣고 **저장**.
   (키는 윈도우 계정 암호화로 저장됩니다.)
3. 블로그 글 하나로 영상을 끝까지 만들어 보고, 결과가 괜찮은지 확인합니다.

## 4. 지인용 설치 파일 만들기 (키 포함, 파일 하나)

1. 같은 **설정** 화면 아래의 **"지인용 설치 파일 만들기"** 로 갑니다.
2. 1번에서 받은 `BlogVideo-Setup.exe` 를 고르고 **"키 넣은 설치 파일 만들기"** 를 누릅니다.
3. 다운로드 폴더에 **`블로그영상변환기_설치_키포함.exe`** 가 생깁니다. 이 파일 **하나만** 지인에게 보내세요.
   - 이 과정은 내 PC 안에서만 이루어지고, 키가 인터넷이나 GitHub로 나가지 않습니다.
4. 지인은 그 파일을 실행해 설치하면 끝입니다. **키를 따로 넣지 않아도 바로 쓸 수 있습니다.**
   처음 실행할 때 키가 지인 PC의 윈도우 계정 암호화로 옮겨 저장됩니다.

> ⚠️ **키 포함 설치 파일 취급 주의**
> - 이 파일에는 API 키가 숨어 있습니다(암호화가 아니라 숨김). 파일을 가진 사람은 마음먹으면 키를 꺼낼 수 있습니다.
> - **지인에게만 직접** 보내고, 인터넷·단체방·공개 드라이브에 올리지 마세요. 보낸 뒤에는 내 PC의 파일도 지우세요.
> - 이 프로그램 **전용 키**를 쓰고 **월 사용 한도**를 꼭 걸어 두세요. 문제가 생기면 콘솔에서 그 키만 끄고, 새 키로 다시 만들면 됩니다.
> - 키를 바꾸면 내 PC 설정에 새 키를 저장한 뒤 이 과정을 다시 해서 새 파일을 보내면 됩니다. 지인이 새 파일로 설치하면 키가 바뀝니다.

### 누가 쓸 수 있나
- 프로그램은 **그 PC 안에서만** 열립니다(127.0.0.1). 같은 와이파이의 휴대폰·다른 PC는 접속할 수 없습니다.
- 설치 프로그램은 방화벽을 열지 않습니다.
- 다른 웹사이트가 이 프로그램에 몰래 요청을 보내는 것도 막아 두었습니다.
- GitHub에서 받는 기본 설치 파일에는 키가 없습니다. 키는 4번에서 만든 파일에만 들어 있습니다.
- 지인 PC의 설정 파일을 다른 PC로 복사해 가도 키를 풀 수 없습니다(윈도우 계정 암호화).

## 5. 업데이트

새 설치 파일을 받아 그대로 실행하면 덮어써집니다. 저장된 API 키와 추가한 배경음악은 그대로 남습니다.

## 6. 데이터 위치 (문제 해결용)

| 내용 | 위치 |
|---|---|
| 설정(API 키), 추가한 배경음악, 로그 | `%APPDATA%\BlogVideo\` (`logs\app.log`) |
| 작업 파일(사진, 음성, 영상) — 7일 지나면 자동 삭제 | `%LOCALAPPDATA%\BlogVideo\jobs\` |

문제가 생기면 `logs\app.log` 와 해당 작업 폴더의 `render.log` 를 보면 원인을 알 수 있습니다.

## 7. 알아 둘 점

- **유튜브 자동 업로드는 넣지 않았습니다.** 구글 심사를 받지 않은 앱으로 API 업로드를 하면 영상이 비공개로 잠기기 때문입니다. 대신 영상 저장 + 제목/설명/태그 복사 버튼을 제공합니다.
- **네이버 블로그 구조가 바뀌면** 글 읽기가 실패할 수 있습니다. `app/scraper/naver.py` 만 고치면 됩니다.
- **성우(Edge TTS)는 마이크로소프트의 비공식 무료 서비스**를 씁니다. 막히면 `app/tts.py` 의 음성 엔진을 바꿔야 합니다.
- **내장 배경음악 3곡**은 코드로 직접 합성한 곡(CC0)이라 저작권 걱정이 없습니다. 다른 음악은 사용 허락이 확인된 MP3만 추가하세요.
- 설치 파일에는 FFmpeg(GPL)가 포함되어 있으며, 라이선스 파일이 설치 폴더의 `_internal\ffmpeg\LICENSE.txt` 에 들어 있습니다.
