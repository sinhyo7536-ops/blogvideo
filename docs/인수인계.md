## 1. 한눈에 보기

네이버 블로그 글 링크를 넣으면 **블로그 사진 + 큰 자막 + AI 성우 + 배경음악**으로 된 MP4를 만드는 **윈도우용 프로그램**이다.
지인(컴퓨터 초보)이 쓸 수 있게 설치 파일 하나로 배포하고, 업로드는 사람이 유튜브에서 직접 한다(반자동).

| 단계 | 사용 기술 | 비용 |
|---|---|---|
| 글·사진 가져오기 | httpx + BeautifulSoup (네이버 모바일 페이지) | 무료 |
| 대본 | Claude API(`claude-opus-5-5`) / **[임시]** Gemini 무료 API / AI 없이 자동 나누기 | Claude만 유료(영상당 약 100~200원) |
| 성우 | Edge TTS (`ko-KR-SunHiNeural`, `ko-KR-InJoonNeural`) | 무료 |
| 영상 | FFmpeg + Pillow(자막 PNG) | 무료 |
| 화면 | FastAPI 로컬 서버 + HTML/JS, Edge **앱 모드 창** | - |
| 배포 | PyInstaller + Inno Setup, GitHub Actions(windows-latest) | - |

현재 상태: 핵심 기능 완성, 자동 테스트 **186개 통과**(리눅스, 브라우저 테스트 포함), Windows CI 빌드·설치·실행 확인 통과.

## 5. 꼭 알아야 할 함정

1. **저장소가 공개다.** API 키를 커밋·GitHub Secrets·Actions 산출물에 절대 넣지 말 것. 키 포함 설치 파일은 프로그램 설정 화면에서 **로컬로만** 만든다.
2. `packaging/` 폴더에 `__init__.py`를 만들지 말 것. 파이썬 `packaging` 라이브러리를 가려서 pip·pytest가 깨진다(그래서 실행기는 `app/launcher.py`).
3. `installer.iss`는 **UTF-8 BOM**으로 저장해야 한글이 안 깨진다.
4. 확대 효과에 FFmpeg `zoompan`을 다시 쓰지 말 것. 정수 픽셀 반올림 때문에 화면이 떨린다(사용자 영상에서 측정됨). `tests/test_render_quality.py::test_zoom_has_no_jitter`가 막아 준다.
5. 학교·회사 네트워크는 HTTPS를 중간에서 검사한다. `netsetup.use_system_certificates()`(truststore)를 실행 초기에 꼭 호출한다.
6. 윈도우에서는 다른 프로그램이 `0.0.0.0:8765`를 잡고 있어도 `127.0.0.1:8765`는 열린다(포트 충돌 테스트가 이것 때문에 한 번 실패했음).
7. Gemini SDK는 기본 **시간 제한이 없다.** `gemini.TIMEOUT_MS`(60초)를 유지할 것.
8. Edge 앱 창은 최소화하면 타이머가 1분 간격으로 느려진다. 그래서 창 닫힘 판단(`Presence.SILENCE`)은 150초이고, 창을 닫을 때는 `pagehide` 신호로 8초 안에 꺼진다.
9. 설치 프로그램은 관리자 권한으로 돈다. 키는 `{userappdata}`로 넘기므로, 다른 관리자 계정 암호로 설치하면 키가 그 계정 쪽에 들어갈 수 있다.
10. Edge TTS는 비공식 엔드포인트(WebSocket)다. 막히면 `app/tts.py`만 교체하면 된다. CI의 "Check real Edge TTS" 단계가 실제 호출을 확인한다.

## 6. 진행 중 / 남은 일

### 6.1 여행 블로그 컨셉 기능 (설계 제안만, 승인 전)
사용자가 참고 영상(비디오스튜, https://www.youtube.com/watch?v=ik9jkHpTvJk)처럼 더 풍부하게 만들고 싶어 함. 참고 영상은 사용자가 직접 올려 줄 예정(유튜브·비디오스튜 사이트는 자동 접속이 막혀서 직접 확인 못 함).
사용자가 고른 방향: **자막 스타일·애니메이션, 다양한 전환·움직임, 여행 블로그 컨셉, 소리·편집은 추천대로.**

제안했던 설계(사용자 확인 전):
- 구성: 인트로 화면(여행 제목·지역·날짜), 장면별 **장소 이름표**("📍 통영 동피랑", AI가 추출), 엔딩 화면(구독 안내·채널 이름), **썸네일 자동 생성**(1280×720)
- 자막: 스타일 3종(깔끔 / 감성(손글씨풍 OFL 폰트 추가) / 브이로그), 아래에서 떠오르는 효과, 핵심 단어 1~2개 노란색 강조
- 움직임·전환: 장면마다 확대/축소/좌우·상하 이동(지금의 떨림 없는 방식으로), 장면 전환 여러 종(FFmpeg `xfade`), "자동 다양하게 / 부드럽게" 선택
- 소리·편집: 성우 속도(느리게/보통/빠르게), 한국어 목소리 추가 + 미리 듣기, 한 장면에 사진 최대 3장, SRT 자막 파일 저장
- 제외: 지도 화면(지도 API 유료 키 필요) → 장소 이름표로 대체
- 정해야 할 것: 채널 이름을 어디서 가져올지(설정 입력 / 블로그 이름 자동 / 넣지 않기)

구현 힌트:
- 대본 모델(`ScriptDraft`, `Scene`)에 `place`, `keywords` 필드 추가 → Claude·Gemini 프롬프트와 스키마 둘 다 수정
- 전환은 장면 클립을 만든 뒤 `xfade`로 이어 붙이면 되고, 그러면 전체 길이가 전환 시간만큼 줄어드니 오디오(`acrossfade`)도 맞출 것
- 움직임 종류는 `render._scene_clip`의 `scale…crop` 식에서 crop 위치(x, y)를 시간에 따라 바꾸면 된다(정수 반올림 떨림 주의 → 2배 크기에서 계산 후 축소 유지)

### 6.2 Gemini 제거 (사용자가 "제미나이 빼 줘"라고 하면)
Gemini 관련 코드는 모두 `app/gemini.py`와 `[임시]` 표시가 붙은 줄에 있다.
1. `app/gemini.py`, `tests/test_gemini.py` 삭제
2. `[임시]`를 검색해서 해당 줄 정리: `models.py`(mode `gemini`), `jobs.py`(Steps.gemini_*), `main.py`(default_steps, 모드 검사, /api/info `has_gemini_key`), `config.py`(`SECRET_KEYS`에서 `gemini_api_key`), `web/index.html`·`app.js`(Gemini 버튼·설정 칸·`saveGeminiKey`), `pyproject.toml`(`google-genai`), `packaging/blogvideo.spec`(collect_submodules, `app.gemini`)
3. `keybundle.py`는 키 묶음(JSON) 형식을 그대로 둬도 된다(Claude 키만 들어감)
4. 문서: `배포안내.md`의 "(임시) Gemini 무료 API 키 만들기", `사용설명서.md`의 Gemini 줄, `README.md`의 `app/gemini.py` 줄
5. 사용자에게: 설정에 Claude 키 저장 → **지인용 설치 파일을 다시 만들어** 전달

### 6.3 아직 실제로 확인 못 한 것
- **Claude API 실제 호출**(키 없음, 가짜 응답·요청 형식만 검증). 크레딧이 들어오면 실제 글 1편으로 확인 필요
- 학교 네트워크 인증서 문제가 truststore로 해결됐는지(사용자 재시도 결과 미확인). 실패 시 오류 문구 괄호 안 내용과 `app.log` 확인
- Edge 앱 창 열기·창 닫으면 종료 동작의 **실제 PC 확인**(Windows CI·리눅스 브라우저로는 확인)
- 원본 사진 다운로드로 사진이 커져서 편집 화면 썸네일이 무거울 수 있음(작은 미리보기 이미지 따로 만드는 개선 여지)

### 6.4 미뤄 둔 작은 문제 (최종 검토에서 나온 것)
- 자막이 약 110자를 넘으면 3줄 + "…"로 잘림(성우는 끝까지 읽음)
- "AI 없이" 대본은 긴 문장을 60자에서 잘라 문장이 끊길 수 있음
- 오래된 네이버 링크 형식(`?Redirect=Log&logNo=`)과 "제목 + 링크"로 복사한 공유 문구는 인식 못 함
- 옛 에디터(SmartEditor 2) 글은 "전체공개 확인" 안내가 나옴(실제로는 형식 미지원)
- 같은 작업을 두 탭에서 동시에 "영상 만들기"하면 두 번 렌더링될 수 있음
- 음악 업로드 파일 이름 처리(80자 자름, 같은 이름 덮어쓰기, 크기 제한 없음)
- `KeyError`를 404로 처리해서 코드 버그가 "작업을 찾을 수 없어요"로 보일 수 있음
- 앱 업데이트 직후 예전 JS가 캐시에 남을 수 있음(정적 파일에 버전 쿼리 없음)
- `fastapi>=0.110` 하한이 Range 지원 버전보다 낮음(올릴 것)
