## 1. 한눈에 보기

네이버 블로그 글 링크를 넣으면 **블로그 사진 + 큰 자막 + AI 성우 + 배경음악**으로 된 MP4를 만드는 **윈도우용 프로그램**이다.
지인(컴퓨터 초보)이 쓸 수 있게 설치 파일 하나로 배포하고, 업로드는 사람이 유튜브에서 직접 한다(반자동).

| 단계 | 사용 기술 | 비용 |
|---|---|---|
| 글·사진 가져오기 | httpx + BeautifulSoup (네이버 모바일 페이지) | 무료 |
| 대본 | Claude API(`claude-opus-5-5`) / Gemini 무료 API / AI 없이 자동 나누기 | Claude만 유료(영상당 약 100~200원) |
| 성우 | Edge TTS (`ko-KR-SunHiNeural`, `ko-KR-InJoonNeural`) | 무료 |
| 영상 | FFmpeg(전환 xfade, 사진 확대·이동) + Pillow(자막·제목 띠·시작/끝 화면·썸네일) | 무료 |
| 화면 | FastAPI 로컬 서버 + HTML/JS, Edge **앱 모드 창** | - |
| 배포 | PyInstaller + Inno Setup, GitHub Actions(windows-latest) | - |

현재 상태: 핵심 기능 완성, 자동 테스트 **186개 통과**(리눅스, 브라우저 테스트 포함), Windows CI 빌드·설치·실행 확인 통과.

## 5. 꼭 알아야 할 함정

1. **저장소가 공개다.** API 키를 커밋·GitHub Secrets·Actions 산출물에 절대 넣지 말 것. 키 포함 설치 파일은 프로그램 설정 화면에서 **로컬로만** 만든다.
2. `packaging/` 폴더에 `__init__.py`를 만들지 말 것. 파이썬 `packaging` 라이브러리를 가려서 pip·pytest가 깨진다(그래서 실행기는 `app/launcher.py`).
3. `installer.iss`는 **UTF-8 BOM**으로 저장해야 한글이 안 깨진다.
4. 확대 효과에 FFmpeg `zoompan`을 다시 쓰지 말 것. 정수 픽셀 반올림 때문에 화면이 떨린다(사용자 영상에서 측정됨). `tests/test_render_quality.py::test_zoom_has_no_jitter`가 막아 준다.
5. 학교·회사 네트워크는 HTTPS를 중간에서 검사한다. `netsetup.use_system_certificates()`(truststore)를 실행 초기에 꼭 호출한다.
6. 윈도우에서는 다른 프로그램이 `0.0.0.0:8765`를 잡고 있어도 `127.0.0.1:8765`는 열린다(포트 충돌 테스트가 이것 때문에 한 번 실패했음).
7. Gemini SDK는 기본 **시간 제한이 없다.** `gemini.TIMEOUT_MS`(60초)를 유지할 것.
8. Edge 앱 창은 최소화하면 타이머가 1분 간격으로 느려진다. 그래서 창 닫힘 판단(`Presence.SILENCE`)은 150초이고, 창을 닫을 때는 `pagehide` 신호로 8초 안에 꺼진다.
9. 설치 프로그램은 관리자 권한으로 돈다. 키는 `{userappdata}`로 넘기므로, 다른 관리자 계정 암호로 설치하면 키가 그 계정 쪽에 들어갈 수 있다.
10. Edge TTS는 비공식 엔드포인트(WebSocket)다. 막히면 `app/tts.py`만 교체하면 된다. CI의 "Check real Edge TTS" 단계가 실제 호출을 확인한다.

## 6. 진행 중 / 남은 일

### 6.1 여행 블로그 영상 기능 (2026-11-12 구현, 브랜치 `feat/travel-video`)
참고 영상(비디오스튜 "부동산 매물 소개 블로그를 영상으로 변환하기", https://www.youtube.com/watch?v=ik9jkHpTvJk)을
직접 확인했다. 블로그 주소 입력 → 글·사진 확인 → 템플릿 선택 → 배경음악·목소리 → 편집 → 렌더링 흐름이고,
완성본은 왼쪽 위 **제목 띠** + 아래 **검은 상자 자막** + 인트로/본문/아웃트로 구성이다. 이를 여행 글에 맞게 옮겼다.

구현한 것:
- **스타일 3종**(`RenderOptions.template`): 깔끔(파란 띠·검은 상자 자막) / 감성(상자 없는 자막·느린 겹침) / 브이로그(노란 형광펜 자막·빠른 전환)
- **시작 화면**(3초, 첫 사진을 흐리게 깔고 여행 제목·둘째 줄), **끝 화면**(3.5초, 감사 인사·구독 부탁·채널 이름)
- **제목 띠 + 장소 이름표**: `VideoScript.intro_title`, `Scene.place`. Claude·Gemini가 원문에서 뽑고, 편집 화면에서 고칠 수 있다
- **전환**: 장면 사이 FFmpeg `xfade`. `RenderOptions.effects` = `auto`(스타일별 여러 종) / `soft`(겹침만)
- **사진 움직임**: 확대·축소·좌우·상하 이동을 장면마다 돌아가며 사용(`render.MOTIONS`)
- **자막 떠오르기**: 장면 시작 0.35초 동안 아래에서 올라오며 나타남
- **썸네일**: `render/thumbnail.jpg`(1280×720), `GET /api/jobs/{id}/thumbnail`, 결과 화면에 저장 버튼
- **채널 이름**: 설정 `channel_name`(암호화 대상 아님). 비면 `BlogPost.blog_name`(og:site_name)

알아 둘 구조:
- 장면 조각은 **소리 없이** 만들고 뒤 장면과 겹칠 시간만큼 길게 만든다. 전환은 다음 장면의 소리가 시작되는 순간부터
  겹치므로 **전체 길이 = 장면 길이의 합**(목소리는 겹치지 않는다). 마지막에 한 번 더 인코딩한다(`render._join`).
- 예전에 저장된 작업(state.json)은 새 필드가 기본값으로 채워져 그대로 열린다.
- 넣지 않은 것: 요약(핵심 정리) 화면, 손글씨 폰트, 성우 속도 조절, 한 장면 여러 사진, SRT 저장, 지도 화면

### 6.1-2 기능 나누기: 불러오기 → 추천대로 / 직접 작성 (2026-11-12 구현)
사용자 요청: "블로그 주소를 넣으면 사진과 내용을 불러오고, **추천대로 작성**은 AI가 사진과 글을 매치시켜 만들고,
**직접 작성**은 사진과 텍스트를 직접 골라 내가 입력. 장면마다 효과·전환·자막."

- **단계**: `scraping → loaded`(글·사진만 불러옴) `→ scripting → ready → tts → rendering → done`.
  `POST /api/jobs {mode:"load"}` 로 불러오고, `POST /api/jobs/{id}/write {mode}` 로 작성한다
  (`api`·`gemini`·`auto` = 추천대로, `manual` = 직접 작성: 장면이 빈 대본으로 바로 `ready`).
  작성 단계가 실패하면 `failed_phase="script"` 라서 다시 시도해도 글을 또 받지 않는다.
- **AI가 사진을 본다**: `script.photos_for_ai()` 가 사진을 768px로 줄여 최대 20장(많으면 고르게) 번호와 함께 보낸다.
  Claude는 image 블록, Gemini는 `Part.from_bytes`. 내려받은 사진이 없으면 예전처럼 글만 보낸다.
- **장면별 효과**: `Scene.motion`(확대·축소·좌우·상하 이동·없음), `Scene.transition`(이 장면으로 들어올 때의 전환 7종).
  기본값 `auto` 는 스타일의 기본 순서를 쓴다. AI가 추천 값을 채우고, 편집 화면의 장면 카드에서 바꿀 수 있다.
  모르는 값은 `auto` 로 바뀐다(모델이 엉뚱한 이름을 내도 안전). 전환 이름 → FFmpeg xfade 는 `render.XFADE`.
- **화면**: 처음 화면은 주소 칸과 "블로그 불러오기"만. 영상 설정(스타일·모양·화질·목소리·음악)은 편집 화면으로 옮겼다.
  편집 화면의 "블로그 글·사진에서 가져오기"에서 문단·사진을 눌러 장면을 추가한다.
- **화면용 작은 사진**: `GET /api/jobs/{id}/image/{n}?small=1` (480px, 사진 폴더에 `small_NN.jpg` 로 저장). 원본은 영상에만 쓴다.
- 예전 방식(`POST /api/jobs {mode:"api"}` 로 한 번에 대본까지)은 그대로 동작한다(테스트·호환용).

### 6.1-3 글 전체 담기 · 목소리 넓히기 · 유튜브 링크 배경음악 (2026-11-12 구현)
- **글 전체 담기(영상 길이 제한 없음)**: AI 프롬프트에서 "장면 6~12개" 제한을 없애고 "글의 모든 내용을 순서대로 빠짐없이"로 바꿨다.
  "AI 없이"도 문장을 골라내지 않고 전부 장면으로 만든다. AI에게 보여 주는 사진은 최대 30장.
  편집 화면에 "장면 N개 · 예상 길이"를 보여 주고, 사용자가 장면을 지우거나 더해 길이를 정한다.
- **긴 영상 합성**: 장면이 많으면 FFmpeg 한 번에 다 넘길 수 없어서(입력 수·윈도우 명령 길이 약 3만 자) `render._join` 이
  `GROUP`(8)개씩 묶어 중간 파일(`part_L_NNN.mkv`, 무압축 소리)로 만들고 묶음끼리 다시 잇는다. 묶음 경계에서도 전환이 이어진다.
  FFmpeg 9에서 `-filter_complex_script` 가 없어져서 필터는 인자로 직접 넘긴다(묶음이 작아 길이 문제 없음).
- **성우 음성 동시 생성**: `tts.PARALLEL`(4)개씩 동시에 만든다(장면 24개 약 30초).
- **목소리**: `tts.VOICE_LIST` 13종(`models.VOICE_KEYS` 와 순서까지 같아야 함). 한국어 전용 Edge 목소리는 3개뿐이라
  높낮이를 바꾼 3종과 한국어를 읽는 다국어 목소리 7종을 더했다. `RenderOptions.speed`(slow/normal/fast).
  미리 듣기 `POST /api/voice-preview`(설정 폴더 `previews/` 에 저장해 다시 씀), 목록 `GET /api/voices`.
  예전 값 `female`/`male` 은 그대로 쓸 수 있다.
- **유튜브 링크 배경음악**: `app/ytmusic.py`(yt-dlp). `POST /api/music/youtube {url}` → 내 음악 폴더에 `제목.mp3`.
  유튜브 주소만 받고(다른 사이트·file:// 거부), 30분 넘는 영상·라이브는 거부. 미리 듣기 `GET /api/music/file/{name}`.
  화면에 "허락된 음악만" 경고를 넣었다. **yt-dlp는 유튜브가 바뀌면 자주 깨진다** → 안 되면 `pip install -U yt-dlp` 후 다시 빌드.

### 6.2 Gemini는 유지
예전 계획(크레딧이 들어오면 Gemini 제거)은 **취소**됐다. Claude와 Gemini를 둘 다 정식으로 둔다.
코드의 `[임시]` 표시는 모두 지웠다. 대본 형식을 바꿀 때는 두 곳을 함께 고친다:
`app/script.py`(프롬프트 `SYSTEM`, `ScriptDraft`)와 `app/gemini.py`(`SCHEMA`).

### 6.3 아직 실제로 확인 못 한 것
- **Claude·Gemini API 실제 호출로 사진을 보고 고른 장면·움직임·전환, 장소 이름·여행 제목이 잘 나오는지**(이 PC에 키 없음, 가짜 응답·요청 형식만 검증). 키를 넣고 실제 여행 글 1편으로 확인 필요
- 다국어 목소리 7종의 **한국어 억양 품질**(소리를 직접 들어 보지 못함. 어색하면 `VOICE_LIST` 에서 빼면 된다)
- 새 영상 기능의 **설치 파일 빌드**(Windows CI)와 내장 FFmpeg에서의 `xfade` 동작. 이 PC의 FFmpeg 9.0과 실제 네이버 글·실제 Edge TTS로는 확인함
- 학교 네트워크 인증서 문제가 truststore로 해결됐는지(사용자 재시도 결과 미확인). 실패 시 오류 문구 괄호 안 내용과 `app.log` 확인
- Edge 앱 창 열기·창 닫으면 종료 동작의 **실제 PC 확인**(Windows CI·리눅스 브라우저로는 확인)

### 6.4 미뤄 둔 작은 문제 (최종 검토에서 나온 것)
- 자막이 약 110자를 넘으면 3줄 + "…"로 잘림(성우는 끝까지 읽음)
- "AI 없이" 대본은 긴 문장을 60자에서 잘라 문장이 끊길 수 있음
- 오래된 네이버 링크 형식(`?Redirect=Log&logNo=`)과 "제목 + 링크"로 복사한 공유 문구는 인식 못 함
- 옛 에디터(SmartEditor 2) 글은 "전체공개 확인" 안내가 나옴(실제로는 형식 미지원)
- 같은 작업을 두 탭에서 동시에 "영상 만들기"하면 두 번 렌더링될 수 있음
- 음악 업로드 파일 이름 처리(80자 자름, 같은 이름 덮어쓰기, 크기 제한 없음)
- `KeyError`를 404로 처리해서 코드 버그가 "작업을 찾을 수 없어요"로 보일 수 있음
- 앱 업데이트 직후 예전 JS가 캐시에 남을 수 있음(정적 파일에 버전 쿼리 없음)
- `fastapi>=0.110` 하한이 Range 지원 버전보다 낮음(올릴 것)
